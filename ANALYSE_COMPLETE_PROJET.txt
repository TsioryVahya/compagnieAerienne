4. RÈGLES DE GESTION IDENTIFIÉES
═══════════════════════════════════════════════════════════════════════════════

RG01 - Un vol est défini par un aéroport de départ, un aéroport d'arrivée 
       et une durée en heures.

RG02 - Une programmation de vol doit être associée à un vol existant, 
       un avion et une date/heure précise.

RG03 - Un avion possède un matricule unique et une capacité totale de places.

RG04 - Les places d'un avion sont réparties en classes (Économique, Business, 
       Première) via la table classe_place.

RG05 - Chaque classe dans un avion a un intervalle de places défini 
       (place_debut, place_fin).

RG06 - Un pilote peut être affecté à plusieurs avions à des dates différentes.

RG07 - Un avion peut avoir plusieurs pilotes affectés à des dates différentes.

RG08 - Un vol programmé peut avoir plusieurs statuts au cours du temps 
       (Prévu, Confirmé, En cours, Atterri, Annulé).

RG09 - Le statut actuel d'un vol programmé est le dernier enregistré 
       dans l'historique.

RG10 - Une réservation est faite par un client pour un vol programmé spécifique.

RG11 - Une réservation peut contenir plusieurs places (nombre_places).

RG12 - Chaque place réservée doit avoir un type de passager 
       (Adulte, Enfant, Bébé, Senior).

RG13 - Le tarif d'une place dépend de : vol programmé, classe et type de passager.

RG14 - Des remises tarifaires peuvent être appliquées selon le type de passager.

RG15 - Une remise peut être en pourcentage (%) ou en valeur fixe (-).

RG16 - Une remise tarifaire est calculée par rapport à un type de passager 
       de référence (ex: Enfant -30% par rapport à Adulte).

RG17 - Une réservation peut changer de statut (En attente, Confirmée, 
       Payée, Annulée).

RG18 - L'historique de réservation garde la trace de tous les changements 
       de statut.

RG19 - Des produits extras (repas, boissons, etc.) peuvent être vendus 
       aux clients.

RG20 - Un produit extra peut avoir plusieurs tarifs dans le temps.

RG21 - Le tarif actuel d'un produit est celui avec la date d'application 
       la plus récente.

RG22 - Une vente de produits est associée à un client et contient plusieurs 
       détails (produit, quantité, prix unitaire).

RG23 - Des sociétés externes peuvent acheter des espaces publicitaires 
       (diffusions).

RG24 - Une diffusion publicitaire appartient à une société et peut être 
       programmée sur plusieurs vols.

RG25 - Une programmation de diffusion précise le nombre de diffusions 
       pour un vol donné.

RG26 - Les tarifs de publicité varient dans le temps (table tarif_pub).

RG27 - Le paiement d'une diffusion peut être effectué en plusieurs fois 
       (payment_details_diffusion).

RG28 - Le chiffre d'affaires total d'un vol programmé = CA réservations + 
       CA produits extras + CA publicités.

RG29 - Le nombre de places disponibles pour un vol = capacité avion - 
       places déjà réservées.

RG30 - Un client ne peut pas réserver une place déjà occupée sur le même vol.

5. SYNTHÈSE DES VUES ET REQUÊTES COMPLEXES
═══════════════════════════════════════════════════════════════════════════════

VUE 1 : Places disponibles par vol programmé
─────────────────────────────────────────────
SELECT 
    vp.id,
    vp.date_heure,
    v.id_aeroport_depart,
    v.id_aeroport_arrivee,
    av.capacite,
    COALESCE(SUM(r.nombre_places), 0) as places_reservees,
    (av.capacite - COALESCE(SUM(r.nombre_places), 0)) as places_disponibles
FROM vol_programmation vp
INNER JOIN vol v ON vp.id_vol = v.id
INNER JOIN avion av ON vp.id_avion = av.id
LEFT JOIN reservation r ON vp.id = r.id_vol_programmation
GROUP BY vp.id, vp.date_heure, v.id_aeroport_depart, 
         v.id_aeroport_arrivee, av.capacite;

VUE 2 : Chiffre d'affaires par vol programmé
─────────────────────────────────────────────
SELECT 
    vp.id,
    vp.date_heure,
    COALESCE(SUM(tv.tarif), 0) as ca_reservations,
    -- CA produits et publicités nécessitent des jointures supplémentaires
FROM vol_programmation vp
LEFT JOIN reservation r ON vp.id = r.id_vol_programmation
LEFT JOIN reservation_place rp ON r.id = rp.id_reservation
LEFT JOIN tarif_vol tv ON vp.id = tv.id_vol_programmation 
    AND rp.id_type_passager = tv.id_type_passager
GROUP BY vp.id, vp.date_heure;

VUE 3 : Statut actuel des vols programmés
──────────────────────────────────────────
SELECT 
    vp.id,
    vps_latest.id_statut,
    sv.nom as statut_nom,
    vps_latest.date
FROM vol_programmation vp
LEFT JOIN (
    SELECT id_vol_programmation, MAX(date) as max_date
    FROM vol_programmation_statut
    GROUP BY id_vol_programmation
) latest ON vp.id = latest.id_vol_programmation
LEFT JOIN vol_programmation_statut vps_latest 
    ON latest.id_vol_programmation = vps_latest.id_vol_programmation
    AND latest.max_date = vps_latest.date
LEFT JOIN statut_vol sv ON vps_latest.id_statut = sv.id;

VUE 4 : Tarif actuel des produits extras
─────────────────────────────────────────
SELECT 
    pe.id,
    pe.nom,
    tpe.prix,
    tpe.date_application
FROM produit_extra pe
LEFT JOIN (
    SELECT id_produit_extra, MAX(date_application) as max_date
    FROM tarif_produit_extra
    WHERE date_application <= CURRENT_DATE
    GROUP BY id_produit_extra
) latest ON pe.id = latest.id_produit_extra
LEFT JOIN tarif_produit_extra tpe 
    ON latest.id_produit_extra = tpe.id_produit_extra
    AND latest.max_date = tpe.date_application;
